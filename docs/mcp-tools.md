# MCP tools

Everything GameTrace can do is reachable over **MCP (Model Context Protocol)** — the same surface a
human uses in the Web UI. Connect to `http://127.0.0.1:8781/mcp` (Streamable HTTP) or
`http://127.0.0.1:8781/sse` (SSE), with `Authorization: Bearer <token>` when the server has
`GT_AUTH_TOKENS` configured.

- [README.md](../README.md) · [README.zh-CN.md](../README.zh-CN.md)
- Don't read this page at runtime: `get_capabilities` returns the same grouping plus recommended
  call chains and the Skill Catalog, and `read_skill` returns the agent skills under
  [`skills/`](../skills).

## By workflow

| Group | Covers | Representative tools |
|-------|--------|----------------------|
| Capture & sessions | Start/stop a capture, follow session state, bind or hot-swap the decoder | `start_capture` · `stop_capture` · `get_session_status` · `set_session_plugin` |
| Probes (remote machines) | Register a machine, capture on it, manage its local archive | `list_probes` · `probe_start_capture` · `probe_import_archive` · `get_agent_download_options` |
| Mobile proxy leases | Per-user/device proxy capture, isolated from other members | `create_proxy_lease` · `start_lease_capture` · `release_proxy_lease` |
| Query the trace | Decoded events, protocol index, connections/streams/frames, rule hits, decode failures | `list_decoded_data` · `get_protocol_catalog` · `list_connections` · `list_session_alerts` · `query_decode_errors` |
| State analysis | Field-level before/after and the protocol chain behind a change | `query_state_changes` · `get_state_change_detail` |
| Plugin development | Scaffold in *your* workspace, connect an instance you started, attribute failures | `scaffold_plugin` · `connect_plugin` · `status_plugin` · `explain_plugin` |
| Plugin verification | Contract checks and bounded sampling against a stopped session, nothing persisted | `test_plugin` · `verify_plugin` · `sample_bytes_plugin` |
| Plugin knowledge | The contract and dev guide served to agents | `get_plugin_contract` · `get_plugin_dev_guide` · `get_capabilities` · `read_skill` |
| Projects & members | Project metadata, bound plugins, check rules that flag abnormal protocol events, membership, identities | `create_project` · `set_project_plugins` · `set_project_rules` · `add_project_member` |
| Raw-packet debug | Plugin-debug only; gated behind `-enable-raw-debug` | `list_raw_packets` · `decode_raw_packets` |
